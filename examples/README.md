# Examples

The tracked files under [`tests/fixtures`](../tests/fixtures/) are the
canonical safe sample inputs used by the regression tests and the CI smoke
test. The root [README smoke-test section](../README.md#for-a-checked-in-smoke-test)
shows how to run them.

Operational logs and generated extracts under ignored `input/` and `output/`
are not examples and must not be promoted into tracked documentation.
