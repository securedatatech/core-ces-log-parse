# Support scripts

The repository currently has no project-specific support scripts. Development
commands are documented in the root [README](../README.md#development), and
automated checks are canonical in the [CI workflow](../.github/workflows/ci.yml).

This scoped index prevents an empty or generic scripts directory from being
mistaken for an undocumented automation surface. Add a script here only when
it has a project-specific, repeatable purpose.
