# Operator how-to index

These procedures route operators to the current CLI documentation rather
than restating command details:

- [Operational extraction](../../../README.md#usage) explains the supported
  log, sender-list, and output arguments.
- [Checked-in smoke test](../../../README.md#for-a-checked-in-smoke-test)
  provides a safe sample using tracked fixtures.
- [Operator runbooks](../runbooks/README.md) covers local failure and output
  handling.

Raw operational logs and generated extracts belong in the ignored `input/`
and `output/` directories, not in tracked documentation or fixtures.
