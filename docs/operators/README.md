# Operator documentation

Use this section when running the packaged local CLI against Cisco ESA log
inputs. The root [README usage section](../../README.md#usage) is canonical
for command syntax and output selection.

- [How-to index](how-to/README.md): route common extraction tasks to the
  existing usage and smoke-test guidance.
- [Runbook index](runbooks/README.md): route input, output, and failure
  handling guidance.

This repository does not contain a daemon or remote service. Operational data
under the local `input/` and `output/` directories is intentionally ignored
by Git.
