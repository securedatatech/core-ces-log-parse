# CLI reference

The supported entry point is the Python module
`core_ces_log_parse.main`. Use the root [usage examples](../../../README.md#usage)
for invocation and output selection; use [`main.py`](../../../src/core_ces_log_parse/main.py)
for the implementation-level argument and validation behavior.

No separate console-script name is currently published in
`pyproject.toml`. Adding one would be a deliberate packaging-interface
change, not a documentation-only alias.
